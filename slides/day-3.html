DS · Mechanism

How it actually works

A concept becomes useful when it changes what students notice, compare or judge. Systems reveals interdependence; power reveals control and unequal effects; values reveals priorities in security, openness and recovery.

DS · Pathways

Support and extension

Support

Use one prompt per concept and rank only systems, power and values first.

Extension

Show how the concepts interact: explain how one system design decision redistributes power and expresses values.

Enter the Inquiry
Speaker notes

Support changes access to the same essential skill. It does not hide the target technique.

DS · Evidence

Checkpoint and exit

Checkpoint

The two selected concepts produce different insights, and each connection contains a mechanism, stakeholder and evidence reference.

Exit question

Which concept would become less useful if this attack happened to a small private company, and why?

Speaker notes
