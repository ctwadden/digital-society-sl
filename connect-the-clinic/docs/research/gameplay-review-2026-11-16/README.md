# Gameplay research and first-client redesign

**16 November 2026 · Connect the Clinic 0.6.0 · research and proposed implementation contract**

The current opening explains a small connection task clearly, but the student has too little responsibility for a client outcome. This review investigates Aspire's gameplay, graphics and level structure, checks the published clinic and its actual simulation, and specifies a more substantial first job.

**The proposed Opening Shift is not implemented.** The [current game](https://ctwadden.github.io/digital-society-sl/connect-the-clinic/dist/) remains the existing 0.6.0 teacher-review build.

## Which document governs the next build?

`FIRST_CLIENT_MISSION.md` is the lead's proposed contract. The specialist field notes and audit contain recommendations; they do not override its explicit fixtures, costs or acceptance criteria. The existing runtime contract remains authoritative until an implementation deliberately versions it and preserves prior saves/evidence.
