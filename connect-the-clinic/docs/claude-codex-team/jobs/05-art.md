# Codex job 05 — Art direction and original assets

## Assignment

You are the art specialist working for Claude Code. Give the apprenticeship a coherent, appealing visual world that makes its equipment and actions understandable. Satisfy **R1, R2, R4 and R5**. Read `docs/claude-codex-team/WORKER_CONTRACT.md` and the task packet. Deliver integrated-use assets, not only a mood board.

## Skills

Read `learning-simulation-interface` and, for authorized raster work, `imagegen` when locally available. A skill name does not provide an image tool. Inspect actual capabilities; do not add paid API billing or a new service. If unavailable, use suitable original code-native art or return the precise production limitation. Use the common contract and this brief throughout.

## Inputs

Read the corrected handoff, assigned scene/interaction beats, UI dimensions, model device/port IDs and current manifest. Reference Aspire only for general presentation observations. Do not copy proprietary maps, characters, branding, dialogue, artwork or code.

## Owned outputs

Proposed defaults: `dist/apprenticeship/assets/`, `dist/apprenticeship/assets/manifest.json` and `docs/apprenticeship/ART.md`. The exact task allowlist controls writes. UI, model and shared entry files belong to their owners. Coordinate placement and state interfaces before expanding the asset set.

## Deliverable

Establish an original 2D/isometric or cutaway style with consistent camera angle, scale, palette, lighting and materials. Produce the assigned mentor, service vehicle, clinic, equipment and close-ups. Make network devices recognizable at play size. Separate background atmosphere from live equipment, cables and state overlays. Avoid baked-in essential text or artwork suggesting a connection or success the learner has not produced.

Create one representative scene for lead inspection in the running browser before bulk production. Provide stable asset IDs, actual filenames, dimensions, anchor/placement guidance, state variants, provenance, license/creation notes and fallbacks. Preserve editable sources where available. Optimize local loading; do not assume a network image service is available at school.

## Concrete checks

Inspect intended-size rendering with real controls and overlays. Confirm correct port counts/types, coherent proportions, readable silhouettes and clear separation of clickable equipment. Test missing-asset fallback with the interface owner. Confirm essential distinctions also have text or shape cues. Record file sizes and actual inspected environment; avoid claiming device performance from visual inspection alone. Original artwork must improve the playable scene, not remain a separate illustration.

## Budget and result

One bounded asset pass plus one focused repair. After repeated failure, explain the cause and change the production approach with Claude. Return status, changed paths, manifest entries, provenance, inspected renders, limitations and integration instructions. Do not publish or create additional agents.
