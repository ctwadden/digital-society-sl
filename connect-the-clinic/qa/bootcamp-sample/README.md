# Synthetic published-browser bootcamp sample

These files are the lead developer's synthetic QA campaign, not student work, a model answer for grading, or evidence that a student understands the material.

- `progress.json`: actual final browser download, validated by the production programme validator; six training tasks and no independent field work.
- `evidence.json`: actual detailed evidence download, exactly matching production regeneration from that progress.
- `../BOOTCAMP_EVIDENCE_SAMPLE.txt`: actual readable teacher export from the same campaign.
- `../BOOTCAMP_DOWNLOAD_VERIFY.json`: runtime commit, observed byte counts, SHA-256 hashes and verification scope.

The full interaction is recorded in `../BOOTCAMP_BROWSER.md`. Training and trainer demonstrations remain separate from independent field evidence. Files are locally editable and import checks consistency, not identity. Importing this QA progress would intentionally replace a local campaign; it is supplied for developer review and recovery reproduction, not for a learner to claim their own work.
