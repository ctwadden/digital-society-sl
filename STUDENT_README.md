# IB Digital Society SL Week 1 Student Files

This pack supports the British Library cyberattack inquiry.

1. Open `operation-7-dossier.html`; it is the master workspace for all seven gates and can be printed or saved as PDF.
2. Read `case-brief.txt`, then open the primary sources linked on the course page.
3. Complete `source-matrix-template.txt` and `system-map-template.svg` for Gates 1–3.
4. Add two distinct stakeholders, selected 3Cs, conditional implications, a counter-perspective and a named trade-off for Gates 4–6.
5. Use `operation-7-calibration.html` to compare weak, secure and Grade-7-oriented responses before revising Gate 7.
6. Draft with `paper1-planner.txt`; the final response must use attributed evidence and a qualified judgement.

The case brief is a starting synthesis. Cite the original sources, distinguish evidence from inference, and do not treat the interactive safeguard model as a real risk calculator.
