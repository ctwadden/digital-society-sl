# IB Digital Society SL Week 1 Student Files

This pack supports the British Library cyberattack inquiry.

1. Read `case-brief.txt`, then open the primary sources linked on the course page.
2. Complete one `source-matrix-template.txt` for each source.
3. Use `system-map-template.svg` to show mechanisms, stakeholders, effects, safeguards and feedback.
4. Draft with `paper1-planner.txt`; your final paragraph must use specific attributed evidence and a qualified judgement.

The case brief is a starting synthesis. Cite the original sources, distinguish evidence from inference, and do not treat the interactive safeguard model as a real risk calculator.
