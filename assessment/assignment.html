IB Digital Society SL · Week 1 · Detailed assignment

British Library Source-Lens Dossier

Complete an Operation 7 dossier on the British Library cyberattack, then use it to produce one source-grounded Paper 1-style response with a qualified judgement.

Download all student filesPrintable briefRubric

Audience, purpose and success

Operation 7 is the compulsory workflow, not an optional label. Every class completes new gates and the final response is rejected for revision when a gate is missing.

  • All seven Operation 7 gates must be traceable.
  • Use at least two attributed sources.
  • Distinguish fact, inference and unknown.
  • End with a conditional degree judgement.

Class-by-class milestones

Class A · Gates 1–3: establish what can be claimedDefine the technology/system, reconstruct the supported incident-and-recovery mechanism, mark unknowns and complete the British Library/ICO/NCSC evidence matrix.
Class B · Gates 4–6: analyse significanceDifferentiate stakeholders, select the strongest 3Cs, build impact-to-implication chains, then add a source-grounded counter-perspective and trade-off.
Class C · Gate 7: judge and calibrateWrite the response from the dossier, compare it with weak/secure/Grade-7-oriented exemplars, revise the weakest gate and defend the final degree judgement.

Pathways that add real complexity

Tier 1 · Structured dossier

Use the seven labelled frames and sentence stems; every Operation 7 gate must still contain case evidence.

Tier 2 · Independent synthesis

Choose and organize evidence independently while maintaining all seven gates and explicit source limitations.

Tier 3 · Transfer challenge

Apply Operation 7 to a second digital-society case and compare how context changes the judgement.

Required evidence

Production / inquiry defence

  1. Show the exact evidence behind your strongest decision.
  2. Name one failure or limitation and demonstrate the repair or qualification.
  3. Respond to one unpredictable teacher prompt without rehearsed wording.
  4. Explain what you would transfer to a new asset, audience, format or case.

Submission route

  1. Finish Parts 1–4 and answer the student checks.
  2. Open every file before submitting.
  3. Use the rubric to name one secure criterion and one revision target.
  4. Submit the final product, editable/process evidence and defence record together.
