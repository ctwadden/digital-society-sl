# British Library Source-Lens Dossier

Complete an Operation 7 dossier on the British Library cyberattack, then use it to produce one source-grounded Paper 1-style response with a qualified judgement.

## Milestones

- **Class A · Gates 1–3: establish what can be claimed:** Define the technology/system, reconstruct the supported incident-and-recovery mechanism, mark unknowns and complete the British Library/ICO/NCSC evidence matrix.
- **Class B · Gates 4–6: analyse significance:** Differentiate stakeholders, select the strongest 3Cs, build impact-to-implication chains, then add a source-grounded counter-perspective and trade-off.
- **Class C · Gate 7: judge and calibrate:** Write the response from the dossier, compare it with weak/secure/Grade-7-oriented exemplars, revise the weakest gate and defend the final degree judgement.

## Evidence

- [ ] Gate 1: precise technology and system definition
- [ ] Gate 2: annotated causal mechanism with supported, inferred and unknown links
- [ ] Gate 3: three-source evidence matrix with usefulness and limitation
- [ ] Gate 4: two distinct stakeholders and selected 3C lenses
- [ ] Gate 5: impact-to-implication chains with timeframe and condition
- [ ] Gate 6: evidence-based counter-perspective and named trade-off
- [ ] Gate 7: calibrated Paper 1-style response with qualified judgement

## Defence

Show one strong decision, one repair or qualification, one evidence-led revision and one live transfer/edit.
