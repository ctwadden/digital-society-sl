1Day 1 · 70 minutes

Operation 7 Gates 1–3: claim only what evidence supports

What happened, how did it work and what can the sources actually establish?

Open slides
HOOK

Open with the catalogue-going-dark scenario. Students distinguish what they observe, what they infer and what remains unknown.

TEACH

Technology/system definition, access and privilege, exfiltration, service loss, recovery, fact versus inference, source origin/purpose/usefulness/limitation and triangulation.

HOW IT ACTUALLY WORKS

Responsible analysis separates the technical chain from the evidence chain. Every causal arrow needs a source, an inference label or an explicit unknown marker.

2Day 2 · 70 minutes

Operation 7 Gates 4–6: analyse significance

For whom did the system failure matter, through which lens and with what trade-off?

Open slides
HOOK

Assign the same supported fact to four stakeholders and compare how the consequence changes.

TEACH

Stakeholder differentiation, concepts/content/contexts, immediate impact, conditional implication, timeframe, probability, counter-perspective and trade-off.

HOW IT ACTUALLY WORKS

The same technical event produces unequal consequences because stakeholders occupy different positions in the system. Evaluation tests the first claim against evidence that qualifies it and choices that sacrifice one value for another.

3Day 3 · 70 minutes

Operation 7 Gate 7: judge, calibrate and defend

How does the completed dossier become a Grade-7-oriented judgement?

Open slides
HOOK

Compare weak, secure and Grade-7-oriented responses. Highlight the first sentence where the level changes and explain why.

TEACH

Question deconstruction, claim-led organization, precise evidence, mechanism, stakeholder synthesis, counter-perspective, trade-off, extent language, conditions, uncertainty and calibration.

HOW IT ACTUALLY WORKS

A qualified judgement answers the degree of the question, identifies for whom and under what conditions, weighs the strongest counter-evidence and states what uncertainty limits the conclusion.

Three-class assignment sprint

British Library Source-Lens Dossier

Operation 7 is the compulsory workflow, not an optional label. Every class completes new gates and the final response is rejected for revision when a gate is missing.

1. Class A · Gates 1–3: establish what can be claimed

Define the technology/system, reconstruct the supported incident-and-recovery mechanism, mark unknowns and complete the British Library/ICO/NCSC evidence matrix.

2. Class B · Gates 4–6: analyse significance

Differentiate stakeholders, select the strongest 3Cs, build impact-to-implication chains, then add a source-grounded counter-perspective and trade-off.

3. Class C · Gate 7: judge and calibrate

Write the response from the dossier, compare it with weak/secure/Grade-7-oriented exemplars, revise the weakest gate and defend the final degree judgement.

Pathways that add real complexity

Tier 1 · Structured dossier

Use the seven labelled frames and sentence stems; every Operation 7 gate must still contain case evidence.

Tier 2 · Independent synthesis

Choose and organize evidence independently while maintaining all seven gates and explicit source limitations.

Tier 3 · Transfer challenge

Apply Operation 7 to a second digital-society case and compare how context changes the judgement.

Retrieval check

Can you explain the decisions?

1. Which local planning code represents systems thinking?

Answer: The teacher-built framework uses DS-U02-006 for systems; U02-005 is space.

2. Which statement is an implication?

Answer: An implication extends an impact into plausible longer-term significance and states a condition.

3. What makes a concept analytical?

Answer: A useful concept changes the question, explanation or judgement.

4. What should a source evaluation state?

Answer: Source usefulness depends on the claim, origin and limitation.

5. What belongs in a conditional judgement?

Answer: High-level judgement remains evidence-based and qualified.
