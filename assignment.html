Complete an Operation 7 dossier on the British Library cyberattack, then use it to produce one source-grounded Paper 1-style response with a qualified judgement.

Assignment duration: three full 70-minute classes. Each class completes named Operation 7 gates and preserves evidence in one unified dossier.

Teacher-created Paper 1-style practice

Evaluate the extent to which the British Library cyberattack shows that power in digital society depends on control of infrastructure.

This is original classroom practice, not an official IB examination question.

Three-class sprint

Class A · Gates 1–3: establish what can be claimedDefine the technology/system, reconstruct the supported incident-and-recovery mechanism, mark unknowns and complete the British Library/ICO/NCSC evidence matrix.
Class B · Gates 4–6: analyse significanceDifferentiate stakeholders, select the strongest 3Cs, build impact-to-implication chains, then add a source-grounded counter-perspective and trade-off.
Class C · Gate 7: judge and calibrateWrite the response from the dossier, compare it with weak/secure/Grade-7-oriented exemplars, revise the weakest gate and defend the final degree judgement.

Pathways that add real complexity

Tier 1Structured dossierUse the seven labelled frames and sentence stems; every Operation 7 gate must still contain case evidence.
Tier 2Independent synthesisChoose and organize evidence independently while maintaining all seven gates and explicit source limitations.
Tier 3Transfer challengeApply Operation 7 to a second digital-society case and compare how context changes the judgement.

Operation 7 completion gates

  1. Technology and the precise digital system
  2. How it works: supported causal mechanism
  3. Attributed evidence with origin, usefulness and limitation
  4. Distinct stakeholders plus the strongest 3C lenses
  5. Immediate impact and conditional implication
  6. Counter-perspective and genuine trade-off
  7. Qualified judgement: extent, conditions and uncertainty

Required evidence

  1. Gate 1: precise technology and system definition
  2. Gate 2: annotated causal mechanism with supported, inferred and unknown links
  3. Gate 3: three-source evidence matrix with usefulness and limitation
  4. Gate 4: two distinct stakeholders and selected 3C lenses
  5. Gate 5: impact-to-implication chains with timeframe and condition
  6. Gate 6: evidence-based counter-perspective and named trade-off
  7. Gate 7: calibrated Paper 1-style response with qualified judgement

Foundation checkpoints
