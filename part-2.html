Step 6

Triangulate one mechanism claim

Evidence matrix

Step 8

Gate 4: differentiate two stakeholders

Stakeholder map

Hotkey: Not applicable — use the named organizer.

Expected result
Each has a role, interest, lost capability and source-backed evidence
Why this matters
People are affected through their system position
Warning — common failure
Writing that everyone was affected
Repair it
Name the role and exact capability
Step 9

Select the strongest 3C lenses

Concept ranker

Hotkey: Not applicable — use the named organizer.

Expected result
Two concepts explain different dimensions and connect to content/context
Why this matters
A concept earns its place by changing the analysis
Warning — common failure
Listing all seven
Repair it
Rank only the lenses with causal reach
Step 10

Gate 5: write immediate impacts

Impact chain

Hotkey: Not applicable — use the named organizer.

Expected result
Each impact follows directly from a supported event for a named stakeholder
Why this matters
Near-term causality grounds the response
Warning — common failure
Jumping to a dramatic future
Repair it
Begin with what changed in access or work
Step 11

Extend into conditional implications

Implication frame

Hotkey: Not applicable — use the named organizer.

Expected result
Longer-term significance includes timeframe, likelihood and a condition
Why this matters
Measured language protects accuracy
Warning — common failure
Predicting certain catastrophe
Repair it
Use may/could if and name the limit
