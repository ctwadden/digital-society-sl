1Day 1 · 70 minutes

The catalogue goes dark

What does a digital failure reveal about society?

Open slides
HOOK

Begin with an unavailable-catalogue screen and a table of researchers, staff, publishers and the public. Predict what each person can no longer do.

TEACH

Digital society, digital systems, impacts, implications, inquiry, claims, evidence and the 3Cs.

HOW IT ACTUALLY WORKS

A digital society inquiry connects a technical system with people, institutions and consequences. The British Library case makes this connection visible because the physical collection survived while systems for discovering and requesting knowledge failed.

2Day 2 · 70 minutes

How the incident produced disruption

Where did risk and power enter the system?

Open slides
HOOK

Arrange six mechanism cards: access, privilege, data removal, encryption/destruction, service loss and recovery.

TEACH

Remote access, administrator privilege, multi-factor authentication, exfiltration, encryption, backup, legacy infrastructure and recovery environment.

HOW IT ACTUALLY WORKS

The public evidence does not prove every technical step. The case supports a cautious chain: attackers gained privileged access; missing MFA increased exposure; attackers removed data and damaged server infrastructure; tightly connected legacy systems made secure restoration difficult.

MATERIALS
Mechanism cardsBritish Library incident reviewICO statementSimplified system lab
1

Build the supported sequence

LOCATION · Source cards
EXPECTED RESULTEach mechanism stage has a source label
WHY THIS MATTERSCausal claims need evidence at the correct stage
COMMON ERRORFilling gaps with assumptions
REPAIRMark unknown links with a question symbol
2

Locate the human decision points

LOCATION · System map
EXPECTED RESULTMFA, access control, investment and incident response connect to named actors
WHY THIS MATTERSTechnology choices also distribute authority
COMMON ERRORBlaming 'the computer'
REPAIRName the actor who controls the safeguard
3

Test one safeguard

LOCATION · System laboratory
EXPECTED RESULTChanging MFA alters access exposure but does not guarantee prevention
WHY THIS MATTERSSafeguards reduce specific risks rather than create certainty
COMMON ERRORClaiming one control stops all attacks
REPAIRState which stage it affects and what remains
4

Test network segmentation

LOCATION · System laboratory
EXPECTED RESULTSegmentation changes the possible blast radius in the simplified model
WHY THIS MATTERSArchitecture shapes how a local compromise spreads
COMMON ERRORTreating the model as a real forecast
REPAIRDescribe it as a relationship model
5

Trace backup to recovery

LOCATION · Impact chain
EXPECTED RESULTSafe collection copies do not equal functioning restoration infrastructure
WHY THIS MATTERSAvailability depends on usable systems as well as stored data
COMMON ERRORSaying 'they had backups, so recovery was easy'
REPAIRSeparate data integrity from service restoration
6

Write a mechanism explanation

LOCATION · Four-sentence scaffold
EXPECTED RESULTThe response uses because, which meant and therefore without exaggeration
WHY THIS MATTERSMechanism turns description into analysis
COMMON ERRORListing security vocabulary
REPAIRConnect each term to the next consequence
CHECKPOINT

SUPPORT

3Day 3 · 70 minutes

Concepts change the question

Which concepts reveal the most about the case?

Open slides
HOOK

Seven groups receive the same case fact and one concept. Each group writes a different question the concept makes possible.

TEACH

Change, expression, identity, power, space, systems and values as analytical lenses.

HOW IT ACTUALLY WORKS

A concept becomes useful when it changes what students notice, compare or judge. Systems reveals interdependence; power reveals control and unequal effects; values reveals priorities in security, openness and recovery.

MATERIALS

REPAIRChange the question, not only the vocabulary
2

Test the strength of each connection

LOCATION · Evidence requirement
EXPECTED RESULTA strong connection includes fact, mechanism and stakeholder
WHY THIS MATTERSConcepts need analytical work
COMMON ERRORNaming 'power' with no controlled resource
REPAIRName who controls what and with which effect
3

Rank the strongest two concepts

LOCATION · Concept ranker
EXPECTED RESULTThe ranking cites what each lens explains better
WHY THIS MATTERSSelection produces depth
COMMON ERRORChoosing the easiest definitions
REPAIRChoose the lenses with the strongest causal reach
4

Connect concept to content

LOCATION · 3C map
EXPECTED RESULTSystems or power connects to networks, data or security
WHY THIS MATTERSContent supplies the technical mechanism

Connect context

4Day 4 · 70 minutes

Impact becomes implication

What changed immediately, and what might that change mean over time?

Open slides
HOOK

Sort twelve statements into fact, impact, implication or unsupported disaster claim.

TEACH

Stakeholder differentiation, immediate impact, longer-term implication, scale, timeframe, probability, counter-perspective and trade-off.

HOW IT ACTUALLY WORKS

An impact follows directly from the incident. An implication describes a plausible longer-term consequence or significance and names the condition on which it depends.

MATERIALS
Stakeholder cardsImpact/implication sorterTrade-off scale
1

Choose two unlike stakeholders

LOCATION · Stakeholder map
EXPECTED RESULTA researcher and staff member, or publisher and public institution, have distinct interests
WHY THIS MATTERSDifference creates analytical depth
COMMON ERRORWriting 'people were affected'
REPAIRName the role and lost capability
2

Write one immediate impact each

LOCATION · Impact chain
EXPECTED RESULTEach impact follows directly from a supported event
WHY THIS MATTERSNear-term causality grounds analysis
COMMON ERRORJumping to remote future harms
REPAIRBegin with what changed in access or work
3

Extend one impact into an implication

LOCATION · Conditional chain
EXPECTED RESULTThe implication includes may/could and a limiting condition
WHY THIS MATTERSMeasured language protects accuracy
COMMON ERRORWriting a certain catastrophe
REPAIRAdd timeframe, likelihood and condition
4

Add a counter-perspective

LOCATION · Evidence matrix
EXPECTED RESULTThe response recognizes services that continued and safeguards that worked
WHY THIS MATTERSEvaluation weighs the whole case
COMMON ERRORTreating counterargument as the opposite opinion
REPAIRUse evidence that qualifies the original claim
5

Name the trade-off

LOCATION · Open access versus secure recovery scale
EXPECTED RESULTThe response identifies what is gained and sacrificed by a recovery priority
WHY THIS MATTERSInstitutions make choices under constraint
COMMON ERRORCalling security and access simple opposites
REPAIRExplain the timing and conditions
6

Write a conditional judgement

LOCATION · Judgement frame
EXPECTED RESULTThe conclusion identifies for whom, under what conditions and with which uncertainty
WHY THIS MATTERSJudgement answers significance, not only summary
COMMON ERRORRepeating the introduction
REPAIRWeigh the strongest evidence and limitation
CHECKPOINT
Two stakeholders have distinct impact chains; at least one implication includes a timeframe and condition; the counter-perspective uses case evidence.
SUPPORT

Use 'In the short term...' and 'A longer-term implication may be... if...'.

CORE EXIT

Rewrite one dramatic claim as a measured, evidence-based implication.

EXTENSION

Judge whether transparency after the incident redistributed power or mainly repaired institutional trust.

5Day 5 · 70 minutes

Source-lens response studio

How does evidence become a qualified judgement?

Open slides
HOOK

Compare a source-by-source paragraph with a claim-led paragraph that combines evidence. Identify which one actually answers the question.

TEACH

Question deconstruction, source origin/purpose, triangulation, PEEL + Evaluate, precise evidence and conditional judgement.

HOW IT ACTUALLY WORKS

Strong responses organize evidence around a claim. Source origin affects what evidence can establish; mechanism explains causality; evaluation weighs stakeholder difference, conditions and uncertainty.

Three-class assignment sprint

British Library Source-Lens Dossier

The full foundation sequence is five classes. The assessed anchor product is deliberately scoped to three production classes and can be compressed to two by combining the final test with Class B.

1. Class A · Establish the case

Separate fact from inference, build the supported attack-and-recovery mechanism and complete the three-source matrix.

2. Class B · Analyse significance

Map two distinct stakeholders, apply the strongest 3C lenses and distinguish immediate impacts from conditional implications.

3. Class C · Evaluate and judge

Write and calibrate one Paper 1-style PEEL + Evaluate paragraph containing a counter-perspective, trade-off and qualified judgement.

Can you explain the decisions?

1. Which local planning code represents systems thinking?

Answer: The teacher-built framework uses DS-U02-006 for systems; U02-005 is space.

2. Which statement is an implication?

Answer: An implication extends an impact into plausible longer-term significance and states a condition.

3. What makes a concept analytical?

Answer: A useful concept changes the question, explanation or judgement.

4. What should a source evaluation state?

Answer: Source usefulness depends on the claim, origin and limitation.

5. What belongs in a conditional judgement?

Answer: High-level judgement remains evidence-based and qualified.
