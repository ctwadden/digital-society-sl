Three-class assignment

Each class adds new learning

Class A · Gates 1–3: establish what can be claimed

Define the technology/system, reconstruct the supported incident-and-recovery mechanism, mark unknowns and complete the British Library/ICO/NCSC evidence matrix.

Class B · Gates 4–6: analyse significance

Differentiate stakeholders, select the strongest 3Cs, build impact-to-implication chains, then add a source-grounded counter-perspective and trade-off.

Class C · Gate 7: judge and calibrate

Write the response from the dossier, compare it with weak/secure/Grade-7-oriented exemplars, revise the weakest gate and defend the final degree judgement.
